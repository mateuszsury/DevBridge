# Presentation assets

`overview.dot` is the editable technical diagram; `overview.svg` is rendered
with Graphviz (`dot -Tsvg overview.dot -o overview.svg`). The diagram describes
the implementation and limits documented in the main README.

`social-preview.source.html` and `social-diagram.dot` are source files for the
1280 × 640 `social-preview.png` card. Render the HTML at that viewport with a
local headless browser. The preview-source page is marked `noindex`.

These assets do not claim hardware, benchmark or model-accuracy results.
